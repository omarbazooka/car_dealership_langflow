# Test Drive Policy — Demo Data

This document is synthetic demo knowledge for the technical assessment prototype and must be replaced with the dealership's real policy before production.

Customers can request a test drive for an available vehicle listing. A request requires the customer's name, phone number, selected inventory car ID, preferred date, and preferred time. A request is not a confirmed appointment until the dealership staff reviews it.

Customers should bring a valid driving licence and government-issued identification. The dealership may reschedule a request if the selected vehicle is unavailable or if the requested time slot cannot be accommodated.
